# Сортировка текста А.С.Пушкина "Евгений Онегин"

## Данная программа сортирует текст А.С.Пушкина "Евгений Онегин" в английском переводе 3-мя способами:
1. Сортировка строк по алфавиту слева направо
2. Сортировка строк по алфавиту справа налево
3. Сортировка указателей на строки для приведения текста к исходному виду

## Алгоритм сортировки
Для сортировки был выбран алгоритм *qsort*, т.к. по асимптотике он быстрее, чем *buble_sort*

Реализованы функции для сортировки:
- **run_qsort** – запускающая **my_qsort**
- **my_qsort** – сам алгоритм *qsort*, а именно реализация разделения исходных данных на части для сортировки
- **swap_qsort** – алгоритм сортировки частей данных

Реализованы соответствующие компораторы:
- **my_compare_string_up** – для сортировки в строк в лексеграфическом порядке при порядке сравнения слева направо
- **compare_string_up_from_right_to_left** – сортировки в строк в лексеграфическом порядке при порядке сравнения справа налево
- **compare_string_by_ptr** – для сортировки в строк по указателям в порядке возрастания

## Входные и выходные данные
- входные данные – это текст А.С.Пушкина "Евгений Онегин" в английском переводе, файл **Onegin.txt**
- выходные данные – это отсортированный 3-мя способами текст А.С.Пушкина "Евгений Онегин", файл **out.txt**
- входные данные для отладки – файл **test_text.txt**

## Чтение данных
Для чтения данных реализованы 2 функции с разными походами:
- **read_file_by_lines** – читает массив строк посимвольно
- **read_file_by_lines_one_buf** – читает весь текст за один раз и разбивает его на строки, не расходую дополнитльную память, путем создания указателей на соответсвующие позиции "внутри" считанного текста

> [!NOTE]
> Второй подход ускоряет чтение данных, т.к. при чтении большими блоками накладные расходы сводятся к минимуму

## Хранение строк
Для хранения строк была реализована структура **struct String**, содержащая следующие поля:
- указатель на строку
- длина строки
Что позволяет удобно работать со строкой.

Для оптимизации сортировки сортируются не полные строки, с полным посимвольным swap, а структуры **String**, содержащие указатели на строки. Что позваляет ускорить обмен в сортировке путем уменьшения размера сортируемых элементов.

## Компиляция
Ввести в терминал один из пунктов:

- gcc base.c qsort_prog.c -o qsort_prog

- start compile.bat

## Запуск
Ввести в терминал

- .\qsort_prog

Или вручную запустить

- qsort_prog.exe
